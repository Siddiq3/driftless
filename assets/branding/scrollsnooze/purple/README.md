# ScrollSnooze purple identity

The active theme is midnight `#10102B`, plum `#211C3D`, lavender `#C4A0FF`, soft white `#F7F2FF` and muted lavender `#B9AFCB`. Green success and coral warnings retain separate meaning. The icon has a small moon-yellow accent.

## Active assets

`fresh.png`, `drained.png`, `tired.png`, `focused.png`, `privacy.png`, `wrapped.png` and `friends.png` replace the peach artwork in the runtime components. The earlier peach versions are retained as design sources. Native copies of fresh/drained/focused are in the tracking module's drawable-nodpi folder.

`icon-master.png` is the transparent brain-hugging-paused-phone mark, with no stars, orbit or Z letters. `node scripts/generate-brand-icons.cjs` creates the opaque store icon, adaptive foreground and native launcher/splash resources on midnight. The Expo config plugin repeats generation during prebuild.

Only the display name changes to ScrollSnooze. Package ID, URL scheme, storage keys, authentication and backend identifiers remain stable.

Artwork created using the built-in image_gen tool. Geometry-preserving recolor was requested to retain animation alignment. Native/JS facial colors are now lavender/indigo.

### Launcher icon

Use case: logo-brand. Asset type: transparent square foreground master for ScrollSnooze Android launcher icon. Create a polished clean minimal app emblem in lavender and midnight indigo. One friendly rounded purple brain-cloud character hugging a small midnight indigo phone with a large clear pale lavender PAUSE symbol (two vertical bars) on its screen. The brain has gently closed crescent eyes, a small smile, subtle pink-lilac cheeks, and one S-shaped broad curl in the crown. Simple six-lobed brain silhouette, no realistic anatomy. Head and phone form one tight compact balanced emblem. Soft clean vector-like illustrated volumes, broad readable shapes, very restrained shading, thick smooth dark indigo facial details. Colors lavender #C4A0FF, highlights #E4C5FF, purple shadow #9566DF, midnight #241642, screen #222557, pale #F7F2FF. Add only a tiny buttery yellow crescent peeking behind upper right of brain, at most 15 percent of total emblem, secondary to brain and pause phone. No stars, no orbit ring, no floating Z letters, no other text, no border tile. Center emblem within central 64 percent square safe area, generous even transparent padding for adaptive launcher masks. Full subject visible. True transparent alpha background; no drawn checkerboard or white canvas. Designed to sit on a solid midnight #10102B tile which will be added by build tools. Fresh original professional identity, not a detailed scene.
