# Driftless illustrations

Created with the built-in image_gen tool. Original artwork for Driftless; no BrainPal assets were reused. Transparent PNGs are bundled locally, so rendering does not require a network request. `focus.png` is also copied to the Android tracking module as `res/drawable-nodpi/wick_focus.png` for its native pause activity.

## Final prompts

### wick.png
Use case: stylized-concept. Create a production-ready transparent PNG app mascot cutout: Wick, an original cute plump amber lantern-flame creature for Driftless, a scrolling reduction app. Single full-body character, warm honey orange rounded flame teardrop body with tiny curled tuft on top, very large glossy dark brown eyes with cream highlights, small joyful smile, small stubby arms and feet, pale golden glowing belly and subtle rosy cheeks. Polished soft 3D clay/toy illustration with tactile smooth surface, soft studio lighting, clean silhouette. Front-facing, gently waving, centered, fills 85 percent of square frame. Transparent background, no scene, no text, no logos, no watermark, no brain anatomy, no props. Friendly and expressive, visually rich rather than flat geometric shapes.
