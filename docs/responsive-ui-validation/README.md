# Responsive Android validation

Selected actual Android 16/API 36.1 emulator captures from the responsive UI audit. Guest mode; no real account or billing operations.

Configurations: 320×640dp, 393×850dp, 440×950dp, 360×800dp at 2× system font size, and 800×1280dp. These are configurations of one isolated AVD, not physical devices.

The final keyboard-scrolled capture shows Open invitation and Cancel above the visible software keyboard. Earlier captures in the local output directory were retained as investigation evidence.

See [the complete audit](../responsive-ui-audit.md) for tests, scope and remaining physical-device/account checks.
